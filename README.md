# Economic Outlook — Kiel Institute for the World Economy

An interactive, visualization-first version of a report on the web. The reader scrolls through the story while animated charts step through the data — the visualizations carry the report, the text guides the way. Every figure also comes with a PNG download, so the same charts can be reused in static formats (print, PDF, slides) from a single source.

This edition presents the Kiel Institute's [*Economic Outlook* Nr. 133 (2026 | Q2), "World Economy in Summer 2026: Iran War Still Weighs on Growth"](https://www.kielinstitut.de/), in the institute's own brand: their logo, the Suisse Works / Suisse Intl type pair, and the palette their own figures are drawn in. Three of the report's charts are reproduced — Figure 3 (world trade), Figure 4 (global industrial production) and Figure 5 (raw material prices) — with the report's abstract, chapter text and figure readings alongside them.

The report publishes its charts as images with no data table, so those three series were recovered from the PDF's own pixels; `docs/kiel-figure-digitization.md` records the method, its accuracy, and the one place it falls short. `docs/kiel-brand.md` records where every brand value came from.

For the template itself — project structure, how figures are added, how the PNG export works — see the README on the `main` branch.
