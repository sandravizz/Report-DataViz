# State of Private Markets: Q1 2026 — Interactive Report

An interactive, visualization-first web version of a written report, created as a demo for [Carta](https://carta.com/data/). Not a replacement for the PDF, but a different path alongside it — both formats have their reasons to exist. Here, the reader moves through the content while animated charts bring the data to life, with a special focus on the visualizations themselves. Every figure also has a PNG download button, bridging the two formats from a single source.

This edition presents Carta's *State of Private Markets: Q1 2026*. The figures step through fundraising volume (capital and rounds), the fall of down rounds back to pre-boom levels, post-money valuations by stage, AI's share of venture capital, and where AI capital goes by metro area. Brand setup and figure data provenance live in `docs/carta-brand.md`.

This report is built with my interactive-report template; the template itself (tech stack, project structure, how to add chapters and figures) is documented in the README on the `main` branch.
