# Paris Demo — Interactive Report

An interactive, visualization-first web version of a written report. Not a replacement for the PDF, but a different path alongside it — both formats have their reasons to exist. Here, the reader moves through the content while animated charts bring the data to life, with a special focus on the visualizations themselves. Every figure also has a PNG download button, bridging the two formats from a single source.

This edition takes the structure and UI of the `carta-demo` branch (fixed header with Index sheet, chapter rail, dot-grid cover and chapter openers, highlights, ending screen) in the look of `main`: Satoshi, the Global Justice Project palette and logo. It currently holds three placeholder chapters with no figures; content and data are still to come.

This report is built with my interactive-report template; the template itself (tech stack, project structure, how to add chapters and figures) is documented in the README on the `main` branch.
